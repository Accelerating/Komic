# Komic

[简体中文](README_zh.md)

Komic is an Android comic reader for local files and WebDAV libraries. It runs on Android 8.0 and later.

## Features

- Local image folders and unencrypted ZIP, CBZ, RAR, CBR, 7z, and CB7 comic archives.
- WebDAV folder browsing and comic archive reading.
- Bookshelf with covers, reading history, and automatic progress saving.
- Continuous scrolling, vertical and horizontal paging, zoom, page jumps, and adjustable brightness and screen orientation.
- English and Simplified Chinese interface, light and dark themes, and support for following the system language and theme.
